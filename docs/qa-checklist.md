# PlanP QA Checklist

이 문서는 배포 전 또는 포트폴리오 제출 전 핵심 기능을 직접 확인하기 위한 수동 QA 체크리스트입니다.

## Test Setup

### 실행 준비

- [ ] 루트 의존성 설치: `npm install`
- [ ] 서버 의존성 설치: `npm --prefix server install`
- [ ] 서버 실행: `npm run server:dev`
- [ ] 프론트 실행: `npm run dev`
- [ ] 관리자 계정 생성: `npm --prefix server run seed:admin`
- [ ] 브라우저에서 프론트 접속
- [ ] `http://127.0.0.1:4000/health` 응답 확인

### 테스트 계정

```txt
일반 사용자
ID: testuser01
PW: test1234

관리자
ID: admin01
PW: admin1234
```

## Auth

### 회원가입

- [ ] 회원가입 페이지 진입
- [ ] 필수 값을 입력하고 회원가입 성공 확인
- [ ] 같은 아이디로 다시 가입 시 중복 안내 확인
- [ ] 회원가입 후 로그인 상태로 전환되는지 확인

### 로그인

- [ ] 일반 사용자 계정으로 로그인 성공
- [ ] 잘못된 비밀번호 입력 시 실패 안내 확인
- [ ] 새로고침 후 로그인 상태 유지 확인
- [ ] 로그아웃 후 보호 기능 접근 제한 확인

## Survey

### 비로그인 설문

- [ ] 비로그인 상태에서 홈에서 도시 선택
- [ ] 설문 완료 후 결과 페이지 진입
- [ ] 새로고침 시 DB 저장 기록이 없기 때문에 로그인 저장 기능이 동작하지 않는지 확인

### 로그인 설문 저장

- [ ] 일반 사용자 로그인
- [ ] 홈에서 도쿄 선택
- [ ] 설문 완료 후 결과 페이지 진입
- [ ] 서버 DB의 `survey_results`에 도시별 결과가 저장되는지 확인
- [ ] 같은 도시 설문을 다시 완료하면 새 row가 아니라 기존 row가 갱신되는지 확인

### 이전 기록 복구

- [ ] 설문 결과가 저장된 계정으로 홈 진입
- [ ] 이전에 저장한 도시를 다시 선택
- [ ] 이전 기록 복구 / 새로 작성하기 선택 화면 확인
- [ ] 이전 기록 복구 선택 시 저장된 결과 페이지로 이동 확인
- [ ] 새로 작성하기 선택 시 설문 첫 단계로 이동 확인

## Result Page

### 카테고리 표시

- [ ] 선택한 설문 값에 따라 이동수단, 맛집, 관광, 숙소 영역 표시 확인
- [ ] 쇼핑을 선택한 경우 쇼핑 nav가 표시되는지 확인
- [ ] 쇼핑 nav 클릭 시 준비중 화면 표시 확인

### 결과 카드

- [ ] 맛집 카드 클릭 시 맛집 상세 페이지 이동
- [ ] 관광 카드 클릭 시 관광 상세 페이지 이동
- [ ] 숙소 카드 클릭 시 숙소 상세 페이지 이동
- [ ] 잘못된 상세 URL 접근 시 해당 도시 결과 페이지로 이동

## Favorites

### 관심 항목 저장

- [ ] 로그인 상태에서 결과 카드 또는 상세 페이지 관심 항목 저장
- [ ] 보관함 페이지에서 저장한 항목 확인
- [ ] 같은 항목을 다시 클릭해 삭제 확인
- [ ] 새로고침 후 저장 상태 유지 확인

### 최근 본 항목

- [ ] 로그인 상태에서 맛집/관광/숙소 상세 페이지 진입
- [ ] 보관함에서 최근 본 항목 표시 확인
- [ ] 같은 상세 페이지 재방문 시 최근 본 시간이 갱신되는지 확인

## Booking Click Logs

### 예약 링크 클릭

- [ ] 결과 페이지 또는 상세 페이지에서 외부 예약 링크 클릭
- [ ] 외부 예약 페이지가 새 창 또는 현재 창에서 열리는지 확인
- [ ] 서버 DB의 `booking_clicks`에 클릭 로그 저장 확인
- [ ] 비로그인 상태에서도 클릭 로그가 저장되는지 확인

## Admin

### 접근 제한

- [ ] 비로그인 상태로 `/admin` 접근 시 로그인 페이지 이동 확인
- [ ] 일반 사용자 로그인 후 `/admin` 직접 접근 시 홈으로 이동 확인
- [ ] 일반 사용자 토큰으로 `/admin/stats` API 호출 시 `403` 확인
- [ ] 관리자 계정 로그인 후 `/admin` 접근 성공 확인

### 통계 확인

- [ ] 가장 많이 선택한 도시 통계 표시 확인
- [ ] 도시 선택 순위 표시 확인
- [ ] 도시별 예약 클릭 통계 표시 확인
- [ ] 이동수단, 맛집, 관광, 숙소 클릭 통계 표시 확인
- [ ] 도시 필터 적용 확인
- [ ] 카테고리 필터 적용 확인
- [ ] 기간 필터 적용 확인
- [ ] 데이터가 없는 조건에서 빈 상태 UI 확인

## Performance

### 빌드 확인

- [ ] `npm run build` 성공 확인
- [ ] 빌드 결과에서 기존 1MB 단일 `cityPlaceDetails` 청크가 생성되지 않는지 확인
- [ ] 도시/타입별 `foodPlaceDetails`, `tourPlaceDetails`, `stayPlaceDetails` 청크가 분리되어 생성되는지 확인

### 상세 데이터 로딩

- [ ] 결과 페이지 진입 시 대용량 상세 데이터가 바로 로딩되지 않는지 확인
- [ ] 상세 페이지 진입 시 해당 도시의 상세 데이터 청크만 로딩되는지 확인
- [ ] 상세 페이지 로딩 중 fallback UI가 표시되는지 확인

## Error Handling

- [ ] 서버가 꺼진 상태에서 로그인 요청 시 실패 안내 확인
- [ ] 서버가 꺼진 상태에서 서베이 저장 시 화면 진행이 막히지 않는지 확인
- [ ] 관리자 통계 API 실패 시 에러 상태 표시 확인
- [ ] 토큰이 잘못되었거나 만료된 경우 로그인 필요 상태로 처리되는지 확인

## Regression

- [ ] 홈 화면 도시 선택 정상 동작
- [ ] 탐색 페이지 정상 진입
- [ ] 설문 페이지 단계 이동 정상 동작
- [ ] 결과 페이지 nav 이동 정상 동작
- [ ] 상세 페이지 이미지와 예약 섹션 표시 정상 동작
- [ ] 보관함 페이지 저장 항목 표시 정상 동작
- [ ] 관리자 페이지 레이아웃 깨짐 없음
